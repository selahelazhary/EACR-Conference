# EACR Conference

الموقعُ الرسميُّ للمؤتمر السنويِّ **للجمعيّة المصريّة لأبحاث السرطان ٢٠٢٦**،
المنعقدِ في **المركز القومي للبحوث**.

**تحت رعاية:** الأستاذ الدكتور ممدوح معوّض حسن — رئيسُ المركز القومي للبحوث،
والقائمُ بأعمال رئيس أكاديميّة البحث العلمي والتكنولوجيا.

**رئيسُ المؤتمر:** الأستاذ الدكتور محمد لبيب سالم — رئيسُ الجمعيّة المصريّة
لأبحاث السرطان.

---

## ما هذا الموقع

موقعٌ **ثابتٌ كاملُ الفهرسة** يبنيه مولّدٌ مكتوبٌ بالبايثون، ويقرأ محتواه من
قاعدة Firebase التي تكتب فيها لوحةُ الإدارة. فما تنشره اللجنةُ من اللوحة يصير
صفحاتٍ جاهزةً تقرؤها محرّكاتُ البحث حرفاً حرفاً — لا صفحةً فارغةً تنتظر
جافاسكربت.

| | |
|---|---|
| الأقسام | أخبارٌ · فعاليّاتٌ · ورشُ عمل · متحدّثون · فيديوهاتٌ · صورُ المؤتمر — **وما تضيفه من اللوحة** |
| الداعمون | قائمةُ رعاةٍ بأربعة مستويات، شعارُ كلِّ داعمٍ يُرفع من اللوحة |
| البياناتُ المهيكلة | `Event` · `Person` · `Organization` · `ItemList` · `BreadcrumbList` |
| خريطةُ الموقع | كلُّ صفحةٍ بتاريخ تعديلها · `rss.xml` · فهرسُ بحثٍ داخل المتصفّح |
| العملُ دون إنترنت | عاملُ خدمةٍ + صفحةُ انقطاع + تثبيتٌ كتطبيق |
| الإشعارات | تُطلب عند فتح الموقع، وتصل فورَ نشر أيِّ جديد |
| التصميم | ٤١ تصميماً × ٢٠ تنسيقاً تُبدَّل من اللوحة بلا إعادةِ بناء |

## التشغيل

```bash
pip install -r requirements.txt

python build.py            # بناءٌ من المحتوى الموجود
python build.py --sync     # سحبُ الجديد من Firebase ثمّ البناء
python build.py --serve    # بناءٌ ثمّ معاينةٌ على http://127.0.0.1:8000
python tools/audit.py      # فحصُ الروابط والبيانات المهيكلة بعد البناء
python tools/make_icons.py # إعادةُ توليد الأيقونات من brand/logo-source.png
```

**دورةُ النشر المعتادة:** تنشر من لوحة الإدارة → تُشغّل `python build.py --sync`
→ تدفع التغيير إلى GitHub.

## لوحةُ الإدارة

`/admin.html` — تُبنى مع الموقع من قالبٍ واحد، فأقسامُها وألوانُها تأتي من
`content/site.yml` نفسِه.

**الدخول** ببريدٍ وكلمة مرور عبر Firebase Authentication. لا حسابَ مفتوحٌ ولا
كلمةَ سرٍّ مكتوبةٌ في الشيفرة: الحساباتُ تُنشأ من لوحة Firebase وحدها.

| الشاشة | ما تفعله |
|---|---|
| لوحةُ القيادة | إحصاءُ كلِّ قسم · تنبيهٌ إن كانت هناك موادُّ منشورةٌ لم تدخل البناء |
| كلُّ المواد | جدولٌ واحدٌ لكلِّ الأقسام: بحثٌ وتصفيةٌ وترتيبٌ · تحديدٌ جماعيٌّ · نسخُ مادّة |
| المحرّر | شريطُ أدواتٍ عربيٌّ · جداولُ تبقى كما هي · تنظيفُ اللصق من وورد · **الصورةُ تُرفع ولا تُلصق** · محدِّدُ بؤرة الغلاف · حفظٌ تلقائيٌّ للمسودّة |
| **الأقسام** | **إضافةُ قسمٍ جديدٍ وحذفُه وترتيبُه** · اسمُه ورابطُه ولونُه ووصفُه · **شكلُ عرضه** |
| **الداعمون** | إضافةُ داعمٍ ورفعُ شعاره ورابطُ موقعه ومستوى دعمه وترتيبُه |
| **بياناتُ المؤتمر** | الاسمُ والموعدُ والمكانُ وروابطُ التسجيل · الراعي ورئيسُ المؤتمر بصورهما |
| الموضوعات | إضافةٌ وتسميةٌ وحذفٌ مع عدد المواد |
| الهويّة والتصميم | اسمُ الموقع وشعارُه وأيقونتُه · ٤١ تصميماً بمعاينةٍ حيّة · ٢٠ تنسيقاً · **إخفاءُ أيِّ عنصر** |
| الإعدادات | نسخةٌ احتياطيّةٌ كاملةٌ واستيرادُها · أداةُ تنظيف الصور المضمّنة · تغييرُ كلمة المرور |

## الأقسام: كيف تُضاف وكيف تُعرض

القسمُ ليس اسماً فحسب: له عقدةٌ في قاعدة البيانات، ورابطٌ تُبنى عليه صفحاتُه،
و**شكلُ عرضٍ** يحدّد هيئتَه في الرئيسيّة وفي صفحته:

| الشكل | ما يعرضه | يصلح لـ |
|---|---|---|
| `standard` | بطاقاتٌ بصورةٍ وعنوانٍ وملخّص | الأخبار |
| `agenda` | لوحُ تاريخٍ + موعدٌ + قاعة | الفعاليّات وورشُ العمل |
| `people` | صورةٌ دائريّةٌ واسمٌ وصفة | المتحدّثون |
| `video` | شبكةٌ بعلامة تشغيل | الفيديوهات |
| `gallery` | بلاطاتُ صورٍ متجاورة | صورُ المؤتمر |

أضِف قسماً من **لوحة الإدارة ← الأقسام**، واختر شكلَ عرضه، ثمّ شغّل
`python build.py --sync`. لا يحتاج القسمُ الجديدُ تعديلَ قالبٍ ولا قاعدةَ أمانٍ
ولا سطرَ شيفرةٍ واحد: القوالبُ تسأل عن شكل العرض، وقواعدُ الأمان تعامل أيَّ
عقدةٍ جديدةٍ معاملةَ قسمِ محتوى.

## المحتوى

مصدرانِ يندمجان في قائمةٍ واحدة:

1. **قاعدةُ Firebase** — ما تكتبه لوحةُ الإدارة. يُسحب بـ `--sync` ويُحفظ في
   `content/firebase-snapshot.json` ليُبنى منه.
2. **ملفّاتُ Markdown** في `content/articles/` — لمن يفضّل الكتابة في مُحرِّر
   نصّ. عند تطابق العنوان، المحلّيُّ يتقدّم.

```markdown
---
title: "الجلسةُ الافتتاحيّة"
section: events           # معرّفُ القسم كما في site.yml
date: 2026-11-15
summary: "سطرٌ يظهر في البطاقة ونتائج البحث."
when: "٩:٠٠ ص — ١١:٣٠ ص"
venue: "القاعةُ الكبرى — المركز القومي للبحوث"
image: "https://…"
tags: ["العلاج المناعي"]
---

نصُّ المادّة بصيغة Markdown.
```

الحقولُ `when` و `venue` لأقسام `agenda`، و `role` لأقسام `people`،
و `video` لأقسام `video`.

## الأمان

`firebase-rules.json` في جذر المستودع. **الصقه في**
Firebase Console ← Realtime Database ← Rules ← Publish.

بعده: القراءةُ للجميع، والكتابةُ في المحتوى للمحرّر الداخلِ وحدَه، وللزائر
حقٌّ واحدٌ محدود: زيادةُ عدّادٍ بواحد.

**ثلاثُ خطواتٍ لا تكتمل اللوحةُ بدونها** (كلُّها من لوحة Firebase):

1. Authentication ← Sign-in method ← **فعّل Email/Password**.
2. Authentication ← Users ← **Add user** ببريدك وكلمةِ مرورٍ قويّة.
3. Realtime Database ← Rules ← الصق `firebase-rules.json` ← Publish.
4. Authentication ← Settings ← Authorized domains ← **أضِف نطاقَ الموقع**.
